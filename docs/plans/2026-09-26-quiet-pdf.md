# Quiet PDF Implementation Plan

**Goal:** Ship v1 of Quiet PDF (merge, split, organize, compress) as a static Astro site where all PDF work happens in the browser.

**Architecture:** Astro renders static SEO pages; each tool is a React island. PDF logic lives in pure TypeScript modules (`src/lib/pdf`, `src/lib/compress`) executed inside Web Workers. Design: `docs/plans/2026-09-26-quiet-pdf-design.md`.

**Tech Stack:** Astro, React, TypeScript, pdf-lib, pdfjs-dist, @okathira/ghostpdl-wasm, fflate, @dnd-kit, Vitest, React Testing Library.

---

1. Scaffold Astro (minimal, strict TS) + React + sitemap; Vitest with jsdom for components. Commit.
2. `src/lib/pdf/errors.ts` — `PdfToolError` carrying a user-facing message.
3. `src/lib/pdf/load.ts` — `%PDF-` magic check, encrypted/corrupt detection. Tests incl. encrypted fixture.
4. `src/lib/pdf/ranges.ts` — `parsePageRanges`. Tests for all edge cases.
5. `src/lib/pdf/operations.ts` — `mergePdfs`, `extractPages`, `splitEveryPage`, `organizePages`. Tests on generated PDFs.
6. `src/lib/compress/ghostscript.ts` — `compressPdf(gs, input, level)`. Node integration test.
7. Workers + typed clients: `src/workers/pdf.worker.ts`, `src/workers/compress.worker.ts`, `src/workers/client.ts`.
8. UI building blocks: `DropZone`, `SortableList`, `PageThumbnails` (pdf.js), `download` helper, shared styles.
9. Tool islands: `MergeTool`, `SplitTool`, `OrganizeTool`, `CompressTool`, each with RTL tests (worker client mocked).
10. Pages: layout, header/footer, home, 4 tool pages with How-it-works + FAQ (+ JSON-LD), about, 404. `src/site.ts` config.
11. Launch assets: `public/_headers` (CSP, caching), `robots.txt`, favicon, OG image, sitemap. LICENSE (AGPL-3.0), README.
12. Verify: `npm test`, `astro check`, `npm run build`, manual browser run of every tool with network blocked.
